# Bezels

Add your own .png files to GB, GBC or GBA. Pick one in Settings > Screen >
Game Boy (or Game Boy Color, or Game Boy Advance) > Bezel. slot ships none of
these folders' contents: bezels made by others stay with whoever made them.

Make it the size of the screen:

  Device         Size        Game Boy / Color shows at   GBA shows at
  RG SP          720 x 480   x 120, y 24, 480 x 432      x 0, y 0, 720 x 480
  RG34XX         720 x 480   x 120, y 24, 480 x 432      x 0, y 0, 720 x 480
  RG34XXSP       720 x 480   x 120, y 24, 480 x 432      x 0, y 0, 720 x 480
  Miyoo Flip     640 x 480   x 53, y 0, 533 x 480        x 0, y 27, 640 x 427
  RG35XXSP       640 x 480   x 53, y 0, 533 x 480        x 0, y 27, 640 x 427
  RG35XX Plus    640 x 480   x 53, y 0, 533 x 480        x 0, y 27, 640 x 427
  RG35XX-H       640 x 480   x 53, y 0, 533 x 480        x 0, y 27, 640 x 427
  RG28XX         640 x 480   x 53, y 0, 533 x 480        x 0, y 27, 640 x 427

The bezel is drawn over the game, so leave the game area transparent.

On the 640 x 480 screens a Game Boy picture fills the full height, so a Game
Boy bezel only frames the left and right edges (53 px each side). A GBA
picture fills the full width, so a GBA bezel frames the top and bottom.

Other sizes are scaled to fill and cropped from the centre.
